# 密钥处理

## 1. 原则

1. **快照自包含**。配置文件与 `auth.json` 原样进入快照包，允许出现明文密钥；不做引用化、不做环境变量回写。
2. **不发明私有语法**。快照文件保持宿主可直接读取的形态，不引入需要本应用二次解释的占位。
3. **不整体加密**。加密会让文件无法被宿主直接读取，也制造"必须用本应用"的锁定；风险由用户知情选择。
4. **明示边界**。导出、应用与 WebDAV 上传都必须能说明"密钥会以明文离开本机"。

## 2. `auth.json`

- 纳入快照，只限宿主目录根级的 `agent_dir/auth.json`；子目录里的同名文件仍排除。
- `~/.agents/skills/` 作为第二个受管根进入快照，但它不是宿主目录，根级同名 `auth.json` 同样按子目录文件排除。
- 即使源文件是符号链接，导出时也物化为普通文件；落地时不重建链接，避免凭据指向受管范围外。
- 内容按 Pi 原生结构保存：`{provider: {type: "api_key"|"oauth", ...}}`。
- 空的 `auth.json`（`{}`）仍按普通 auth.json 纳入快照并标记 `plaintextSecrets`；应用端会覆盖目标凭据（覆盖前有备份）。技能盘点的 RPC 可能在缺失时创建空 `auth.json`，UI 必须先提示这个后果。
- 应用时整文件覆盖，不按 provider 合并；本机独有的登录由覆盖前备份兜底。
- POSIX 权限：快照内与落地后都强制 `0600`；快照目录 `0700`。Windows 依赖用户目录继承 ACL。
- OAuth 凭据的 `refresh` token 会在刷新时轮换。多台机器共享同一份 `auth.json` 时，一台刷新后另一台可能 `invalid_grant`；自动上行默认不包含 `auth.json`，避免把失效凭据发布成新包。切换机器前先应用最新快照包。

## 3. 扫描规则

扫描对象：受管范围内的所有文本文件（不只 JSON，包含 `extensions/*.ts`、`skills/**/SKILL.md`、`~/.agents/skills/**`）。

| 规则 | 说明 |
| :--- | :--- |
| 字段名启发式 | 键名匹配 `api[-_]?key`、`token`、`secret`、`password`、`authorization`、`bearer` 等 |
| 已知前缀 | `sk-`、`sk-ant-`、`ghp_`、`github_pat_`、`xox[baprs]-`、`AKIA`、`AIza`、`hf_`、`bce-v3/`、`oc_sk_` 等 |
| 熵阈值 | 长度 ≥ 20 且 Shannon 熵 ≥ 4.5 的连续字符串（排除纯十六进制哈希与版本号） |
| 排除 | `sha256`/`integrity`/`etag` 字段、语义化版本、模型 id、URL 中的公开路径 |

判定分级：

- `high`：命中前缀或字段名+高熵。
- `low`：仅高熵。

扫描只读：命中不阻断导出、不改写文件，只在结果里列出路径、字段名与行号。`auth.json` 不参与逐条展示，由"明文密钥"总开关提示。

## 4. `plaintextSecrets`

manifest 只保留一个布尔标记：

- `true`：快照包含 `auth.json`，或扫描到 `high` 级明文。
- 缺省/`false`：没有 `auth.json`，也没有 `high` 级命中。

导入端据此显示警告；不再生成 `requiredSecrets`，也不再要求用户补齐环境变量。

## 5. 权限与传输

- 打包目录与存储根 `0700`；包内 `auth.json` 与落地后 `auth.json` 均为 `0600`；备份目录 `0700`。
- 本地文件夹模式：云盘客户端会把明文带到服务商与版本历史，设置页必须写明。
- WebDAV：**只接受 HTTPS**；`localhost`/`127.0.0.1`/`::1` 例外。不区分快照是否含 `auth.json`，非 HTTPS 一律拒绝，错误码 `remote_insecure`。
- WebDAV 凭据仍单独存 `webdav.json`，不进快照。

## 6. 禁止项

- 不把密钥写入日志、错误信息或 command 返回值。
- 不在 manifest 中记录密钥值或片段。
- 不对快照整体加密。
- 不做字段级过滤、不代写 OAuth、不自动写 shell 启动文件。
- 不把 `auth.json` 以外的子目录同名文件卷进快照。

## 7. 已知限制

- 快照明文落盘进包；云盘服务商、WebDAV 服务端与其备份/版本历史可见；远端历史包同样含明文。
- OAuth 多机共享不可靠；自动上行默认跳过 `auth.json`。
- 第三方扩展的配置文件若不在受管范围内，本设计覆盖不到。
- `~/.agents/skills` 可能同时被其它 agent 工具使用；快照会原样带走该目录内容，导出/应用都应按“共享目录”提示用户。
