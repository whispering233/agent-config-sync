# 架构

## 1. 技术栈

| 层 | 选型 | 理由 |
| :--- | :--- | :--- |
| 桌面壳 | Tauri v2 | 安装包小；系统 WebView；原生能力（进程、对话框、文件系统）一等公民 |
| 后端 | Rust（stable） | 文件遍历/哈希/并发/子进程都在同一进程内完成，无需 Node 运行时 |
| 前端 | React + TypeScript + Vite | 生态成熟；构建快 |
| 样式 | Tailwind CSS + 全局设计 token | 符合项目样式规则；简单布局不写内联样式 |
| 组件 | shadcn/ui（无头原语组件）+ lucide 图标 | 可组合、可改造，不被组件库主题绑架 |
| 序列化 | serde / serde_json / JSON5 容忍解析 | 宿主配置可能含注释与尾逗号 |
| 哈希 | sha2（SHA-256） | manifest 校验 |
| 遍历 | std::fs + 自定义规则 | 需要符号链接、排除规则与越界防护的精确控制 |
| 网络 | reqwest（阻塞客户端 + rustls 系统根证书） | 只需六个 HTTP 动词，不引 WebDAV SDK；TLS 走系统根，兼容企业代理环境 |
| 压缩 | zip（`default-features = false`，仅 `deflate`） | 快照包容器；必须 >= 9.0（早期版本的 symlink 逃逸洞），关默认 feature 是为了不拉 bzip2/lzma/zstd 一堆 C 依赖 |
| 时间 | std | UTC 时间戳与备份目录命名由核心层格式化 |

约束：**不引入 Node sidecar**。生产环境除调用宿主 CLI 外不依赖 Node。

## 2. 进程与线程边界

```text
[WebView] React
    │ invoke（类型化 command，仅数据）
    ▼
[Rust 主进程]
    ├─ command 层：参数校验、错误映射、事件推送
    ├─ 核心层：纯逻辑 + 文件系统 + 子进程（不依赖 Tauri，可单测）
    └─ 子进程：探测（POSIX 登录 shell / Windows 逐命令）、宿主 CLI、安装脚本
```

- 文件遍历与哈希放阻塞线程池；命令执行统一超时与输出上限。
- 同一时刻最多 2 个子进程。
- 托盘常驻是可选能力：关闭主窗口只隐藏，后台按配置间隔自动上行；只上传，不自动下载/应用，也不监听文件系统。手动上传/下载/应用与自动任务共用操作锁，自动任务拿不到锁就跳过本次。单实例保证第二次启动只唤回已有窗口。
- 出站网络只有 WebDAV 与用户手动触发的 npm 版本查询：控制请求 30s、包传输 120s、版本查询 10s，均不自动重试；失败即停。WebDAV 只接受 HTTPS（本地回环例外），与包内是否含 `auth.json` 无关。
- 前端不直接访问文件系统：所有读写经由 command，前端只持展示状态。

## 3. 模块职责

| 模块 | 职责 | 不负责 |
| :--- | :--- | :--- |
| 应用配置 | 记录同步根目录、宿主目录覆盖、备份保留数 | 记录密钥 |
| 探测 | 通过登录 shell（POSIX）或逐命令（Windows）与路径兜底获取工具/版本/凭据状态 | 修改环境 |
| 环境检测 | 汇总检查项、分级、给出建议动作 id | 执行修复 |
| 快照 | 受管范围遍历、符号链接物化、写 manifest 与指纹、产出完整包内容 | 选择存放方式 |
| 快照包 | 打包/解包、包名生成与解析、解包安全闸门与上限 | 决定快照内容、修改 live |
| 包存储 | 列举、取、原子放入（临时名 → 正式名）、删除、保留清理；实现为本地目录与 WebDAV | 决定快照内容、修改 live 文件、加密 |
| 校验 | manifest 格式/哈希/版本校验 | 修复损坏快照 |
| 计划 | 比较 live 与快照，生成新增/修改/删除候选 | 执行写入 |
| 应用 | 重算计划、备份、写入、删除、失败中止 | 自动重试 |
| 回滚 | 备份列表、还原前备份、按 restore.json 反做 | 修改快照 |
| 密钥 | 明文扫描与告警（只读） | 引用化、补齐环境变量、代写 OAuth |
| 包 | 声明与实装比对、调用宿主安装命令 | 解析包内部、自动移除多余包 |
| 托盘/自动上行 | 托盘菜单与状态提示、启动延迟、定时上行、暂停与立即同步 | 自动下载/应用、冲突自动合并、失败重试 |
| 运行状态 | 手动操作与自动上行共用的互斥锁、开机自启登记 | 排队、监听文件系统 |
| 安装器 | 宿主安装/升级命令的组装与执行（二次探测） | 安装 Node |
| 冲突 | 冲突文件识别与 diff 摘要 | 自动合并、处理动作（未实现） |

模块之间只通过数据结构交互；核心层不感知 UI。安装与包对齐是两段式：`preview` 只探测并给出命令，`execute` 在用户确认后重新探测、重算并校验动作，前端无法传任意命令。

## 4. 数据存放

| 数据 | 位置 | 是否跨机 |
| :--- | :--- | :--- |
| 快照包 | 用户指定的云盘同步文件夹，或 WebDAV 上的 `PiAgentSync/` | ✅ |
| 应用配置 | 系统应用配置目录（Windows 上与数据目录同为 `%APPDATA%\<identifier>`） | ❌ |
| WebDAV 凭据 | 系统应用数据目录下的 `webdav.json`（POSIX 0600，Windows 继承 ACL） | ❌ |
| 远端同步状态 | 系统应用数据目录下的 `remote-state.json`（上次见到的远端包名集合，非密钥） | ❌ |
| 暂存与打包工作区 | 系统应用数据目录下的 `staging/` 与 `upload-workspace/`（中间产物，用完即清） | ❌ |
| 备份与还原清单 | 系统应用数据目录下的备份目录 | ❌ |
| 日志 | 系统应用数据目录下的日志目录 | ❌ |
| 自动上行状态 | 仅内存（托盘 tooltip 与设置页展示）；不落盘 | ❌ |
| 最新版本缓存 | 系统应用配置目录下的 `versions-cache.json`（版本号与时间，非密钥） | ❌ |
| 密钥 | 宿主自己的配置文件（`auth.json` 等） | ✅ 明文随快照 |

快照目录、备份目录权限 `0700`；写入宿主文件时沿用原权限位，`auth.json` 强制 `0600`。

Windows 没有 POSIX 权限位：备份清单的 `mode` 记 `null`，落地与回滚都不设权限；凭据文件的保护改由用户配置目录的默认 ACL 承担。

## 5. 平台矩阵

| 平台 | v1 | 后续 | 已知差异 |
| :--- | :--- | :--- | :--- |
| Linux | ✅ AppImage + deb | 签名仓库 | WebKitGTK 版本差异；无密钥环依赖 |
| Windows | ✅ NSIS（未签名） | 签名、卸载清理钩子 | 官方 installer 的 Portable Git 副作用 → 走 npm；路径大小写；进程树；`cmd /d /s /c` 只为 `.cmd` 中间层；不跨 WSL（不读写 WSL 路径、不在 WSL 内执行命令）；隐藏主窗口后不占任务栏 |
| macOS | 仅设计兼容 | dmg（先不签名） | 需公证才能免 Gatekeeper 拦截；`~/.local/bin` 不在默认 PATH；托盘用 template 图，关闭窗口后切换为 Accessory 策略 |

代码约束：路径一律用平台路径类型；子进程 POSIX 走登录 shell、Windows 走 `cmd /d /s /c`；平台差异用并列实现（编译期分段），不留空实现占位。

## 6. 包依赖链

```text
UI  ──invoke──▶  command 层  ──▶  核心层
                                  ├─ 文件系统 / 哈希 / 遍历
                                  ├─ 子进程（宿主 CLI、安装脚本）
                                  └─ 平台路径与配置目录
```

- 核心层不依赖 Tauri，保证可用临时目录做集成测试。
- 新增依赖的门槛：能用标准库或已有依赖完成的，不引入新 crate/npm 包。目前唯一为快照包引入的 crate 是 `zip`（MIT，`default-features = false` + `deflate`，MSRV 1.89）；自己写 zip 不值得，而 `walkdir` / `similar` 这类需求标准库或现有自研实现已覆盖。
- 版本查询只经 npm CLI，不直接请求 registry；缓存落在应用配置目录，查询失败保留旧缓存。

## 7. 非功能约束

| 项 | 目标 |
| :--- | :--- |
| 启动 | < 1 秒到可用界面（环境检测按需触发） |
| 导出 | 约 100 KB / 千级文件 < 2 秒 |
| 内存 | 常驻 < 150 MB |
| 离线 | 手动导出/应用/回滚不依赖网络；自动上行只使用已配置的 WebDAV；"安装/升级宿主"、"查询最新版本"、"凭据检查"才访问网络 |
| 日志 | 单文件轮转，单文件上限 5 MB，保留 3 份；写入前脱敏 |
| 崩溃 | 不产生半套快照（打包到临时名 + 原子改名）；不产生半套配置（先备份） |

## 8. 安全边界

- Tauri capability 白名单最小化；不启用任意命令执行插件。
- 所有子进程命令由核心层拼接，前端只能传枚举与受限参数。
- 路径参数必须规范化，拒绝越出受管范围或快照目录的路径（防目录穿越）。
- 符号链接不跟随到受管范围之外再写入。
- 日志与错误信息统一脱敏。
- WebDAV 凭据只在传输层使用：不进入快照、日志、错误信息与 command 返回值；WebDAV 只接受 HTTPS（本地回环例外）。
- 自动上行默认不包含 `auth.json`；设置里显式开启后才包含。自动状态只存内存，不落盘、不含凭据。
- 快照包按不可信输入解析：逐条目过白名单、路径与归一化校验、条目数与解压体积上限；不调用库的批量解压接口。

## 9. 测试策略

| 层 | 方式 |
| :--- | :--- |
| 受管范围/排除规则 | 单元测试 + 临时目录夹具 |
| manifest/哈希/指纹 | 单元测试（含损坏、缺文件、版本不支持） |
| 明文密钥扫描 | 单元测试（真阳性样本 + 误报样本 + 只读断言） |
| 计划/应用/回滚 | 临时目录集成测试（构造 live 与快照、符号链接、只读目录） |
| 快照包 | 打包/解包往返一致；越界路径、符号链接条目、条目数/解压体积超限、缺 manifest 全部拒绝 |
| 包存储 | 假 transport 覆盖上传定案与保留清理；本地目录用临时目录夹具 |
| 密钥/包/安装 | 假 Runner 注入，覆盖替换边界、命令矩阵、超时与截断 |
| 托盘/自动上行 | 单实例、关闭到托盘、暂停/立即同步手测；自动上行默认排除 `auth.json` 与 HTTPS 闸门有单元测试 |
| UI | 子代理在真实窗口逐项取证，条目上限固定，避免无限探索 |
