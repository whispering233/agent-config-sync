# 开发任务卡片

> 临时文件。任务完成并验证后必须从本文件删除，不留历史记录。

设计依据：`00-master-design.md`、`10-snapshot-sync.md`、`40-webdav.md`、`architecture.md`。文档已经改完，本清单只列实现。

## 依赖顺序

```text
T0 ──┐
     ├─▶ T1 ─▶ T2 ─┬─▶ T3 ─▶ T4 ─▶ T8
T10  │             └─▶ T5 ─┬─▶ T6 ─▶ T7
     └─────────────────────┴─▶ T9
```

- **T0 必须第一张**：它的结论决定 T1 的上传定案策略。
- **T10 完全独立**，任何时刻可做，适合填空档。
- 其余严格串行：`webdav_transfer.rs`、`commands.rs`、`snapshot-page.tsx` 是共同热点，并行必撞。
- 每张卡都要 Rust 与前端一起改完再提交，否则 `npm run build` 的 `tsc -b` 会红。

## T0 WebDAV 能力真机探测

| 项 | 内容 |
| :--- | :--- |
| 目标 | 用真机定论 `MOVE`、ETag、`getlastmodified`，避免整个上传定案建立在未验证的服务端行为上 |
| 改动 | `webdav.rs` 的 `interop`（ignored）测试：`PUT` 临时名 → `MOVE`（`Overwrite: F`）→ `PROPFIND` 确认 → `DELETE`；记录 `MOVE` 的成功状态码与失败状态码、`GET`/`HEAD` 是否返回 ETag、`PROPFIND` 是否含 `getetag`/`getlastmodified` |
| 验证 | `DAV_URL=… DAV_USER=… DAV_PASS=… cargo test interop -- --ignored --nocapture` |
| 产出 | 更新 `40-webdav.md` §4「待真机复核」的三项，改成实测结论 |
| 回滚 | 只动测试与文档，不影响后续 |
| 阻塞条件 | 若 `MOVE` 不可用：**停下来改设计**（上传定案退回直接 `PUT` 正式名 + 下载端校验），不要继续 T1 |

## T1 快照包格式

| 项 | 内容 |
| :--- | :--- |
| 目标 | 有一个能打包、能安全解包、能解析包名的纯库模块 |
| 改动 | 新增 `src-tauri/src/package.rs`：打包（`snapshot/…` + `manifest.json`，条目全为普通文件）、解包（逐条目过 §2 安全闸门）、包名生成与解析、`.tmp-` 判定；`Cargo.toml` 加 `zip = { version = "9", default-features = false, features = ["deflate"] }` |
| 验证 | 单测：往返一致（内容与 manifest 逐字节相同）；`../`、绝对路径、反斜杠、盘符、条目数超限、解压体积超限、缺 `manifest.json`、出现符号链接条目、超 64 MB 包，逐一断言对应失败码；包名解析对合法/非法样本给出预期结果 |
| 不做 | 不碰 `snapshot.rs`、不碰网络、不碰 UI |
| 回滚 | 新增文件 + 一行依赖，整体删除即回退 |

## T2 包存储抽象

| 项 | 内容 |
| :--- | :--- |
| 目标 | 上传/下载/列举/删除只有一套调用面，本地文件夹与 WebDAV 都实现它 |
| 改动 | 新增 `src-tauri/src/store.rs`：列举（返回可解析包 + 无法识别的文件）、取、原子放入（临时名 → 正式名）、删除、保留清理；两个实现（本地目录用同盘 `fs::rename`，WebDAV 走 `webdav.rs`）；`webdav.rs` 增加 `MOVE` |
| 验证 | 假 transport 覆盖：首次上传时 `MKCOL`、`MOVE` 失败即停且不降级、失败路径清临时名、清理只删可解析且名字严格小于本次包名的份、清理失败不阻塞；本地实现用临时目录夹具跑同一批断言 |
| 不做 | 不接 UI、不改 `commands.rs`、不做 diff |
| 回滚 | 新增文件 + `MOVE` 方法，可独立回退 |

## T3 导出成包

| 项 | 内容 |
| :--- | :--- |
| 目标 | 用户点「导出」得到的是一个快照包，而不是一棵目录树 |
| 改动 | `snapshot.rs`：导出的产物从「目录 + 外部 manifest」改为「一个 zip」，去掉 `swap_in` 的目录替换语义；导出结果改为包名/包大小/文件数/指纹；本地文件夹模式经 T2 的本地存储实现落到存储根；`commands.rs` 与前端导出区跟着改字段 |
| 验证 | 端到端：导出 → 解包 → manifest 与文件逐字节一致；连续导出两次，第二次内容未变时提示跳过；导出中途失败不留下完整包名的文件 |
| 不做 | 不碰 WebDAV 上传、不碰计划与应用 |
| 回滚 | 旧导出路径与新的并存一版即可回退（不合并提交） |

## T4 上传快照包

| 项 | 内容 |
| :--- | :--- |
| 目标 | WebDAV 上传变成「一个包 + 一次保留清理」，请求数从「文件数 + 目录数 + 2」降到约 5 |
| 改动 | `webdav_transfer.rs`：`upload_into` 的逐文件流程整段换成「导出 → 存储放入 → 重新列举 → 保留清理 → 记录状态」；删除 `parent_dirs`、逐文件比对、`commit_headers` 对应的条件写路径；`RemoteState` 换成 `{seenAt, packages[], lastUploadedFingerprint}`；内容未变跳过；`commands.rs` 的 `UploadView` 改为包语义并移除逐文件冲突视图；前端上传区与冲突区重画 |
| 验证 | 端到端 + 假 store 场景：首次上传、新增包、内容未变跳过、清理到 20 份、清理失败仍算上传成功；⚠ 用真机确认正式名下只出现完整包 |
| 依赖 | T2、T3 |
| 回滚 | 单次提交回退；旧上传路径已被删除，回退需连带恢复 `webdav_transfer.rs` 的上一版 |

## T5 下载并解包

| 项 | 内容 |
| :--- | :--- |
| 目标 | 下载一个包、解到暂存目录、交给现有计划与应用，落地链路零改动 |
| 改动 | `webdav_transfer.rs`：`download` 换成「列举 → 取包 → 解包到 `staging/<包名>/`」；删除 `fill_staging` 的逐文件下载与 `write_staged_manifest`；`DownloadOutcome` 带上包信息；`resolve_root` 的暂存白名单保持不变；`commands.rs` 的 `DownloadView` 加包字段；前端下载区展示包名与创建时间 |
| 验证 | 端到端：下载 → 计划 → 应用跑通；坏包（截断 zip、条目越界、哈希不符）不污染 `staging/`；暂存目录只留当前一份；同一份包重复下载结果一致 |
| 依赖 | T1、T2 |
| 回滚 | 单次提交回退 |

| 目标 | 用户能看到远端的历史快照，并指定任意一份来恢复 |

## T7 清理动作

| 项 | 内容 |
| :--- | :--- |
| 目标 | 残留可清，但只能由用户显式触发，且只清它该清的 |
| 改动 | 两个独立动作 + 确认框：「清理上传残留」只删 `.tmp-*`；「删除旧格式快照」只删 `manifest.json` 与 `snapshot/`；其它无法识别的文件只展示、永不可删；结果报出删了哪些 |
| 验证 | 端到端：造一个 `.tmp-*` + 一个旧布局 + 一个外来文件 → 两个动作各自只删自己那一类，外来文件仍在；删除后列表刷新正确 |
| 依赖 | T6 |
| 回滚 | 前端按钮 + 一个命令，整体回退 |

## T8 自动上行适配

| 项 | 内容 |
| :--- | :--- |
| 目标 | 托盘定时上行复用上传链路，不再因云端变化而停止 |
| 改动 | `auto_sync.rs`：状态从 `conflict` 改为 `diverged`（照常上传，只展示「云端有 N 份本机未见的新快照」）；文案从「已上传 N 个文件，跳过 M 个」改为包语义；内容未变时保持 `skipped` |
| 验证 | 单元测试 + 手测：内容未变 → `skipped`；远端有他机新包 → 仍上传成功且状态为 `diverged`；上传失败 → `failed` 且不重试 |
| 依赖 | T4 |
| 回滚 | 单次提交回退 |

## T9 快照包差异对比

| 项 | 内容 |
| :--- | :--- |
| 目标 | 面对多个历史包时，一眼看出「应用哪一个会删掉什么」 |
| 改动 | 新增对比命令：对 1..N 个候选包各自解到 `staging/compare/<包名>/` 跑只读计划，再按 `diff_manifests` 出包与包的差异；对比结束整体清理 `compare/`，常驻暂存仍只留 1 份；前端对比表（「将删除」列最醒目、可展开） |

| 依赖 | T5 |
| 回滚 | 新增命令与前端页面区块，整体回退 |
