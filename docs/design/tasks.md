# 开发任务卡片

> 临时文件。任务完成并验证后必须从本文件删除，不留历史记录。

设计依据：`00-master-design.md`、`10-snapshot-sync.md`、`40-webdav.md`、`architecture.md`。文档已经改完，本清单只列实现。

## 依赖顺序

```text
T0 ──┐
     ├─▶ T1 ─▶ T2 ─┬─▶ T3 ─▶ T4 ─▶ T8
T10  │             │      └─▶ T5 ─┬─▶ T6 ─▶ T7
     └─────────────┴───────────────┴─▶ T9
```

- **T0 必须第一张**：它的结论决定 T1 的上传定案策略。
- **T10 完全独立**，任何时刻可做，适合填空档。
- 其余严格串行：`webdav_transfer.rs`、`commands.rs`、`snapshot-page.tsx` 是共同热点，并行必撞。
- 每张卡都要 Rust 与前端一起改完再提交，否则 `npm run build` 的 `tsc -b` 会红。

> 切片按**传输方式**而不是按层：`snapshot::export*` 同时被本地导出与 WebDAV 上传调用，
> 先改导出再去改上传会让中间态编不过。因此 T3 只把本地模式做成闭环，并**移除逐文件
> WebDAV 传输**（命令改为明确报错）；T4/T5 再分别接上 WebDAV 的写与读。
> 代价是中间态 WebDAV 不可用；好处是每张卡都能编译、能独立验证、能独立回滚。

## T0 WebDAV 能力真机探测

| 项 | 内容 |
| :--- | :--- |
| 目标 | 用真机定论 `MOVE`、ETag、`getlastmodified`，避免整个上传定案建立在未验证的服务端行为上 |
| 改动 | `webdav.rs` 的 `interop`（ignored）测试：`PUT` 临时名 → `MOVE`（`Overwrite: F`）→ `PROPFIND` 确认 → `DELETE`；记录 `MOVE` 的成功状态码与失败状态码、`GET`/`HEAD` 是否返回 ETag、`PROPFIND` 是否含 `getetag`/`getlastmodified` |
| 验证 | `DAV_URL=… DAV_USER=… DAV_PASS=… cargo test interop -- --ignored --nocapture` |
| 产出 | 更新 `40-webdav.md` §4「待真机复核」的三项，改成实测结论 |
| 回滚 | 只动测试与文档，不影响后续 |
| 阻塞条件 | 若 `MOVE` 不可用：**停下来改设计**（上传定案退回直接 `PUT` 正式名 + 下载端校验），不要继续 T1 |

## T1 快照包格式

| 项 | 内容 |
| :--- | :--- |
| 目标 | 有一个能打包、能安全解包、能解析包名的纯库模块 |
| 改动 | 新增 `src-tauri/src/package.rs`：打包（`snapshot/…` + `manifest.json`，条目全为普通文件）、解包（逐条目过 §2 安全闸门）、包名生成与解析、`.tmp-` 判定；`Cargo.toml` 加 `zip = { version = "9", default-features = false, features = ["deflate"] }` |
| 验证 | 单测：往返一致（内容与 manifest 逐字节相同）；`../`、绝对路径、反斜杠、盘符、条目数超限、解压体积超限、缺 `manifest.json`、出现符号链接条目、超 64 MB 包，逐一断言对应失败码；包名解析对合法/非法样本给出预期结果 |
| 不做 | 不碰 `snapshot.rs`、不碰网络、不碰 UI |
| 回滚 | 新增文件 + 一行依赖，整体删除即回退 |

## T2 包存储抽象

| 项 | 内容 |
| :--- | :--- |
| 目标 | 上传/下载/列举/删除只有一套调用面，本地文件夹与 WebDAV 都实现它 |
| 改动 | 新增 `src-tauri/src/store.rs`：列举（返回可解析包 + 无法识别的文件）、取、原子放入（临时名 → 正式名）、删除、保留清理；两个实现（本地目录用同盘 `fs::rename`，WebDAV 走 `webdav.rs`）；`webdav.rs` 增加 `MOVE` |
| 验证 | 假 transport 覆盖：首次上传时 `MKCOL`、`MOVE` 失败即停且不降级、失败路径清临时名、清理只删可解析且名字严格小于本次包名的份、清理失败不阻塞；本地实现用临时目录夹具跑同一批断言 |
| 不做 | 不接 UI、不改 `commands.rs`、不做 diff |
| 回滚 | 新增文件 + `MOVE` 方法，可独立回退 |

## T3 导出成包 + 本地模式闭环

| 项 | 内容 |
| :--- | :--- |
| 目标 | 用户点「导出」得到快照包并落到本地存储根；再从存储根选包恢复，走现有计划与应用 |
| 改动 | `snapshot.rs`：产物从「目录 + 外部 manifest」改为「一个 zip」（经 `package::pack`），删掉 `swap_in`/`restore_point` 等目录替换逻辑；导出结果改为包名/大小/文件数/指纹；内容未变（与存储里最新包的指纹相同）时跳过不产生新包。新增 `package::read_manifest`（只读 zip 里的 `manifest.json`，不整包解压）用于这次比对，也供历史列表显示指纹 |
| | 本地模式：写入与读取都经 T2 的本地实现；下载侧新增「列举存储根 → 选包 → 解包到 `staging/<包名>/` → 交给现有计划」，与 WebDAV 共用同一条链路（只换 store 实现） |
| | **移除逐文件 WebDAV 传输**：`webdav_transfer.rs` 的逐文件上传/下载整段删除，`upload_snapshot`/`download_snapshot` 两个命令在 WebDAV 模式下改为返回可读错误（说明快照包传输尚未接上），不静默降级 |
| | `commands.rs` 的导出/下载视图改包语义；前端导出区与下载区跟着改 |
| 验证 | 端到端：本地模式导出 → 存储根出现一个合法包 → 列举 → 选它 → 计划 → 应用跑通；内容不变再导出时提示跳过且不新增包；坏包（截断/越界/哈希不符）不污染 `staging/`；暂存只留当前一份；WebDAV 模式明确报错而不是走旧路径 |
| 回滚 | 整体回退即可恢复逐文件传输 |

## T4 WebDAV 上传快照包

| 项 | 内容 |
| :--- | :--- |
| 目标 | WebDAV 上传变成「一个包 + 一次保留清理」，请求数从「文件数 + 目录数 + 2」降到约 5 |
| 改动 | 上传命令接到 T2 的 WebDAV 实现：导出 → `put`（`PUT .tmp-*` + `MOVE`）→ 重新列举 → `prune(20)` → 记录 `remote-state.json`；内容未变（完整指纹与 `lastUploadedFingerprint` 相同）跳过；清理失败只上报不阻塞；HTTPS 闸门（非回环地址非 HTTPS 时 `remote_insecure`，且不看包内是否含 `auth.json`）；`UploadView` 改包语义（包名、是否跳过、`pruned`、`pruneFailed`）并移除逐文件冲突视图；前端上传区重画 |
| 验证 | 端到端 + 假 store 场景：首次上传、`MOVE` 失败即停且清临时名、内容未变跳过、清理到 20 份、清理失败仍算上传成功；非 HTTPS 地址不发任何请求 |
| 依赖 | T3 |
| 回滚 | 单次提交回退（WebDAV 回到「明确报错」状态） |

## T5 WebDAV 下载快照包

| 项 | 内容 |
| :--- | :--- |
| 目标 | 远端取包、解包、交给现有计划与应用；下载不改动远端 |
| 改动 | 下载命令接到 T2 的 WebDAV 实现：列举 → 默认取名字最大的包（或指定包）→ `get` → 体积上限（先看列出的 `content-length`）→ 解包到 `staging/<包名>/`；`remote_no_packages` / `package_not_found` / `remote_insecure` 的文案；记录 `remote-state.json` 的包集合与 `seenAt`；`DownloadView` 加包字段；前端下载区展示包名与创建时间 |
| 验证 | 端到端：下载 → 计划 → 应用跑通；远端为空报 `remote_no_packages`；选中后被删报 `package_not_found`；坏包不污染 `staging/`；同一份包重复下载结果一致 |
| 依赖 | T3 |
| 回滚 | 单次提交回退 |

## T7 清理动作

| 项 | 内容 |
| :--- | :--- |
| 目标 | 残留可清，但只能由用户显式触发，且只清它该清的 |
| 改动 | 两个独立动作 + 确认框：「清理上传残留」只删 `.tmp-*`；「删除旧格式快照」只删 `manifest.json` 与 `snapshot/`；其它无法识别的文件只展示、永不可删；结果报出删了哪些 |

## T8 自动上行适配
