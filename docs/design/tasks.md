## T2 应用配置

- 目标：选择并持久化同步根目录与宿主目录覆盖；展示当前生效路径；校验目录关系（禁止快照目录与宿主目录互相嵌套）。
- 验收：重启后配置仍在；非法路径给出可读错误；配置不含任何密钥字段。
- 依赖：无（骨架已就绪）。

## T3 受管范围与遍历

- 目标：按白名单/排除规则遍历宿主目录；符号链接物化并记录；断链跳过；受管范围之外一律不读取内容。
- 验收：用临时目录夹具覆盖：根级 `*.json` 收录、排除项不收录、符号链接物化、断链跳过、路径不含 `..` 越界。
- 依赖：无（骨架已就绪）。

## T4 只读医生

- 目标：探测 node/npm/pi 版本与安装类型、凭据状态、包声明与实装、符号链接、冲突文件、快照状态；输出分级报告。
- 验收：在无 node、无 pi、版本过低、命令坏掉四种夹具下状态正确；全程不写文件；单次检测 < 5 秒（不含网络项）。
- 依赖：T2。

## T5 快照导出

- 目标：收集 → 脱敏 → 扫描 → 写临时目录 → 原子替换 → 写 manifest 与指纹；`high` 级密钥必须显式确认。
- 验收：导出目录与 manifest 一致；哈希可复算；含注释的 JSON 可解析；字面密钥被替换成正确语法的引用；失败时原快照不变。
- 依赖：T2 + T3。

## T6 快照校验与计划

- 目标：读取 manifest、逐文件校验哈希与格式版本；与 live 比较生成新增/修改/删除候选。
- 验收：缺 manifest、版本不支持、哈希不符、删除候选四类用例行为正确；删除仅在受管范围内；计划可序列化给 UI。
- 依赖：T5。

## T7 应用与备份

- 目标：备份 → 写入/删除（删除需勾选）→ 失败中止；展示每项差异摘要。
- 验收：中途失败时 live 可由备份完整还原；未勾选的删除项保留；权限位沿用；范围外文件不被触碰。
- 依赖：T6。

## T8 回滚

- 目标：列出本机备份、按备份还原、还原前再备份一次；保留上限 10。
- 验收：还原后文件内容与权限与备份时一致；超出上限自动清理最旧；损坏备份给出错误而非部分还原。
- 依赖：T7。

## T9 密钥向导

- 目标：展示 manifest 的 `requiredSecrets`；检测环境变量是否存在；提供"复制命令"与"写入本机字面值"两条路；跳过项记为待办。
- 验收：缺失项全部可处理；写入字面值只影响本机；不产生任何日志泄漏；不修改 shell 启动文件。
- 依赖：T7。

## T10 包对齐

- 目标：比对 `settings.json` 的 `packages` 与 `pi list` 实装；展示缺包；用户确认后调用宿主安装命令并刷新状态。
- 验收：缺包与多余包都能识别；命令失败时显示退出码与输出摘要；不自动重试。
- 依赖：T7。

## T11 冲突扫描与处理

- 目标：识别 `*-冲突*` / `*-NSConflict*`；展示与对应原文件的差异摘要；提供保留/替换/暂不处理。
- 验收：两类命名都能识别；处理动作进入备份目录而非直接删除；不做自动合并。
- 依赖：T2。

## T12 宿主安装/升级

- 目标：Linux/macOS 走官方 installer（无终端），Windows 走 npm；安装前展示命令，安装后重跑医生；`pi update` 与 npm 升级按安装类型选择。
- 验收：Node 缺失时给出引导而不执行安装；命令非零退出时展示最后输出；安装成功后能定位入口（含不在 PATH 的情况）。
- 依赖：T4。

## T13 分发

- 目标：Linux AppImage 与 deb；版本信息页；启动自检（缺 WebKitGTK 等给出提示）。
- 验收：干净容器中可安装并启动；产物不含调试符号；不请求网络即可进入界面。
- 依赖：T7。
